# Birbal Sahni

> AI + Robotics project developed during a 21-day practical robotics bootcamp at IIIT-Delhi.

**Birbal Sahni** is a project website created as part of an intensive **AI + Robotics bootcamp at IIIT-Delhi**.

The project was developed during the final practical phase of a multi-stage selection and training process, where participants were progressively filtered through written examinations before reaching the intensive 21-day robotics bootcamp.

The project ultimately secured **2nd place** in the bootcamp.

---

# The Journey

This project was not created as a standalone weekend project.

It was the result of a multi-stage selection process.

The overall journey involved progressively filtering participants through different stages before reaching the final practical phase.

```text
                 Selection Process
                       │
                       ▼
              Written Examination(s)
                       │
                       ▼
                Shortlisting
                       │
                       ▼
             AI + Robotics Bootcamp
                       │
                 21 Days
                       │
                       ▼
              Practical Development
                       │
                       ▼
                 Final Evaluation
                       │
                       ▼
                    🥈 2nd
```

The **21-day bootcamp was the final and most practical stage**, where selected participants had to work hands-on with robotics and AI concepts and turn what they learned into an actual working project.

---

# 21-Day AI + Robotics Bootcamp

The project was developed during a **21-day AI + Robotics practical bootcamp at IIIT-Delhi**.

The bootcamp was designed around hands-on learning rather than only theoretical instruction.

The development process involved working with concepts across areas such as:

- Robotics
- Artificial Intelligence
- Computer Vision
- Programming
- Mechanical systems
- Robot control
- Hardware integration
- 3D/CAD design
- Software development

The final project brought together the concepts explored during the bootcamp into a single practical system.

# Development

The website was built using the Next.js App Router.

To run the project locally:

```bash
git clone https://github.com/Pranabsssssss/Birbal-Sahni.git

cd Birbal-Sahni

npm install

npm run dev
```

Then open:

```text
http://localhost:3000
```

The repository's current setup uses the standard Next.js development workflow.

# Why This Project Matters

For me, this project represents more than just a website.

It represents the final stage of a selection process that went from **written examinations to a 21-day intensive practical AI + Robotics bootcamp**.

The actual challenge was not simply to build something that looked good.

It was about:

- Learning robotics concepts quickly
- Applying AI concepts
- Working with hardware
- Designing and iterating
- Solving problems under time constraints
- Turning concepts into a working project
- Presenting the result for evaluation

The website serves as the digital representation of that work.
